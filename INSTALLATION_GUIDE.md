# 🎮 DreamWorlds — Installation Guide\n\n**Objectif:** Obtenir DreamWorlds fonctionnel en Roblox Studio et jouer en 30 minutes.\n\n---\n\n## ✅ PRÉREQUIS\n\n- Roblox Studio installé ([Télécharger ici](https://www.roblox.com/create))\n- Ce repository cloné ou les fichiers .lua téléchargés\n- 30 minutes de temps\n\n---\n\n## 🔧 ÉTAPE 1: Créer le projet Roblox Studio\n\n### 1.1 Ouvrir Roblox Studio\n- Lancez Roblox Studio\n- Cliquez sur **\"New\"**\n- Sélectionnez **\"Baseplate\"** (c'est le template avec une plateforme vide)\n- Cliquez **\"Create\"**\n\n### 1.2 Attendre le chargement\n```\nLe projet charge...\nVous voyez:\n  - Workspace (zone de jeu)\n  - Des parts vides\n  - L'explorateur sur la gauche\n```\n\n---\n\n## 📁 ÉTAPE 2: Créer la structure des répertoires\n\n### 2.1 Dans ReplicatedStorage\n\n1. **Ouvrir l'Explorateur** (View → Explorer)\n2. **Clic droit sur ReplicatedStorage**\n3. **Insert Object → Folder** → Nommer: **DreamWorlds**\n4. **Clic droit sur DreamWorlds**\n5. **Insert Object → Folder** → Nommer: **Shared**\n6. **Clic droit sur Shared**\n7. **Insert Object → Folder** → Nommer: **Config**\n8. **Clic droit sur DreamWorlds** (pas Shared)\n9. **Insert Object → Folder** → Nommer: **Remotes**\n\n**Résultat attendu:**\n```\nReplicatedStorage\n└── DreamWorlds\n    ├── Shared\n    │   └── Config\n    └── Remotes\n```\n\n### 2.2 Dans ServerScriptService\n\n1. **Clic droit sur ServerScriptService**\n2. **Insert Object → Folder** → Nommer: **DreamWorlds**\n3. **Clic droit sur DreamWorlds**\n4. **Insert Object → Folder** → Nommer: **Services**\n\n**Résultat attendu:**\n```\nServerScriptService\n└── DreamWorlds\n    └── Services\n```\n\n### 2.3 Dans StarterPlayer\n\n1. **Clic droit sur StarterPlayer**\n2. **Insert Object → Folder** → Nommer: **StarterPlayerScripts** (s'il n'existe pas)\n3. **Clic droit sur StarterPlayerScripts**\n4. **Insert Object → Folder** → Nommer: **DreamWorlds**\n\n**Résultat attendu:**\n```\nStarterPlayer\n└── StarterPlayerScripts\n    └── DreamWorlds\n```\n\n---\n\n## 💾 ÉTAPE 3: Copier les fichiers Lua\n\n### 3.1 Configuration Modules (ReplicatedStorage/DreamWorlds/Shared/Config/)\n\n**Créer 5 ModuleScripts :**\n\n#### 3.1.1 GameConfig.lua\n1. **Clic droit sur Config**\n2. **Insert Object → ModuleScript**\n3. **Nommer: GameConfig**\n4. **Double-clic** pour éditer\n5. **Copier le contenu** depuis le fichier `src/shared/Config/GameConfig.lua`\n6. **Ctrl+A, Ctrl+V** (remplacer tout)\n7. **Ctrl+S** pour sauvegarder\n\n#### 3.1.2 BuildConfig.lua\n1. Répéter l'étape 3.1.1 avec le fichier `BuildConfig.lua`\n\n#### 3.1.3 PlotConfig.lua\n1. Répéter l'étape 3.1.1 avec le fichier `PlotConfig.lua`\n\n#### 3.1.4 EconomyConfig.lua\n1. Répéter l'étape 3.1.1 avec le fichier `EconomyConfig.lua`\n\n#### 3.1.5 ItemsConfig.lua\n1. Répéter l'étape 3.1.1 avec le fichier `ItemsConfig.lua`\n\n### 3.2 Remotes Module (ReplicatedStorage/DreamWorlds/)\n\n1. **Clic droit sur DreamWorlds** (dans ReplicatedStorage)\n2. **Insert Object → ModuleScript**\n3. **Nommer: Remotes**\n4. **Double-clic** pour éditer\n5. **Copier le contenu** depuis `src/shared/Remotes.lua`\n6. **Ctrl+S** pour sauvegarder\n\n### 3.3 Server Services (ServerScriptService/DreamWorlds/Services/)\n\n**Créer 4 ModuleScripts :**\n\n#### 3.3.1 DataService.lua\n1. **Clic droit sur Services**\n2. **Insert Object → ModuleScript**\n3. **Nommer: DataService**\n4. **Double-clic** pour éditer\n5. **Copier le contenu** depuis `src/server/Services/DataService.lua`\n6. **Ctrl+S**\n\n#### 3.3.2 PlotService.lua\n1. Répéter pour `PlotService.lua`\n\n#### 3.3.3 BuildService.lua\n1. Répéter pour `BuildService.lua`\n\n#### 3.3.4 EconomyService.lua\n1. Répéter pour `EconomyService.lua`\n\n### 3.4 Server Main Script (ServerScriptService/DreamWorlds/)\n\n1. **Clic droit sur DreamWorlds** (dans ServerScriptService)\n2. **Insert Object → Script** (PAS ModuleScript)\n3. **Nommer: ServerMain**\n4. **Double-clic** pour éditer\n5. **Copier le contenu** depuis `src/server/ServerMain.lua`\n6. **Ctrl+S**\n\n### 3.5 Client Main Script (StarterPlayer/StarterPlayerScripts/DreamWorlds/)\n\n1. **Clic droit sur DreamWorlds** (dans StarterPlayerScripts)\n2. **Insert Object → LocalScript** (PAS ModuleScript)\n3. **Nommer: ClientMain**\n4. **Double-clic** pour éditer\n5. **Copier le contenu** depuis `src/client/ClientMain.lua`\n6. **Ctrl+S**\n\n---\n\n## 🧪 ÉTAPE 4: Tester en Studio\n\n### 4.1 Démarrer le jeu\n1. **Appuyez sur F5** ou **Play button** (triangle vert)\n2. **Attendez 3-5 secondes**\n\n### 4.2 Vérifier la console serveur\n```\nOuverture: View → Output\nVous devriez voir:\n[ServerMain] GameConfig loaded\n[ServerMain] BuildConfig loaded\n[ServerMain] ItemsConfig loaded\n[ServerMain] Remotes loaded\n[ServerMain] Initializing services...\n[DataService] Initializing...\n[PlotService] Initializing...\n[BuildService] Initializing...\n[EconomyService] Initializing...\n[ServerMain] All services initialized successfully!\n```\n\n### 4.3 Attendre la connexion du joueur\n```\nAprès quelques secondes, vous verrez:\n[ServerMain] Player joined: Player1 (UserId)\n[ServerMain] Player received plot: plot_UserId\n```\n\n### 4.4 Vérifier la console client\n```\nOuverture: View → Output\nVous devriez voir:\n[ClientMain] Configs loaded\n[ClientMain] Remotes loaded\n[ClientMain] Requesting player data from server...\n[ClientMain] ✓ Player data loaded:\n  - Level: 1\n  - DreamCoins: 500\n  - XP: 0\n[ClientMain] ✓ Plot data loaded:\n  - Plot ID: plot_UserId\n  - Position: ...\n  - Objects: 0\n[ClientMain] Build mode: OFF\n```\n\n---\n\n## 🎮 ÉTAPE 5: Jouer\n\n### 5.1 Entrer en Build Mode\n- **Appuyez sur B**\n- Console affichera: `Build mode: ON`\n- Vous verrez un **cube vert transparent** suivre votre souris\n\n### 5.2 Placer un objet\n- **Bougez la souris** sur le terrain\n- **Cliquez gauche** pour placer\n- Console affichera: `✓ Object placed: obj_...`\n\n### 5.3 Supprimer un objet\n- **Appuyez sur Delete**\n- Console affichera: `✓ Object deleted: obj_...`\n\n### 5.4 Commandes\n```\nB           → Toggle Build Mode\nClick Gauche → Place object\nDelete      → Delete object\nCtrl+Z      → Undo\nCtrl+Y      → Redo\n```\n\n---\n\n## ❌ TROUBLESHOOTING\n\n### Problème: Erreur \"ModuleScript not found\"\n```\nSolution:\n1. Vérifier que le chemin des folders est correct\n2. Vérifier l'orthographe des noms (case-sensitive)\n3. Vérifier que les ModuleScripts sont dans les bons répertoires\n```\n\n### Problème: Aucun message en console\n```\nSolution:\n1. Vérifier que Output est bien ouvert (View → Output)\n2. Appuyer sur Play (F5) à nouveau\n3. Attendre 5 secondes pour le chargement\n```\n\n### Problème: \"Services not found\" en console\n```\nSolution:\n1. S'assurer que tous les 4 services sont présents\n2. Vérifier les noms exactement: DataService, PlotService, BuildService, EconomyService\n3. Tous doivent être des ModuleScripts dans ServerScriptService/DreamWorlds/Services/\n```\n\n### Problème: Build Mode ne fonctionne pas\n```\nSolution:\n1. Vérifier que ClientMain.lua est dans StarterPlayerScripts/DreamWorlds/\n2. ClientMain doit être un LocalScript (pas ModuleScript)\n3. Relancer le jeu (Stop et Play)\n```\n\n---\n\n## 📊 CHECKPOINTS DE VALIDATION\n\n✅ Vous saurez que ça marche quand:\n\n1. **Console serveur montre \"All services initialized successfully!\"**\n2. **Console client montre \"Player data loaded\" et \"Plot data loaded\"**\n3. **Vous pouvez appuyer sur B et voir le cube vert**\n4. **Vous pouvez cliquer et placer un objet**\n5. **Vous pouvez appuyer sur Delete et supprimer un objet**\n6. **Les messages d'objet placé/supprimé apparaissent en console**\n\n---\n\n## 🚀 PROCHAINES ÉTAPES\n\nUne fois que le jeu fonctionne:\n\n1. Tester en quittant et revenant (vérifier la sauvegarde)\n2. Tester avec 2 joueurs (multiplayer)\n3. Activer DataStore pour une vraie persistance\n4. Ajouter l'UI Build Menu\n5. Ajouter les objets 3D réels\n\n---\n\n## 📞 BESOIN D'AIDE ?\n\nSi vous avez un problème:\n\n1. Vérifier l'Output console (View → Output)\n2. Lire le message d'erreur\n3. Vérifier les chemins des fichiers\n4. Relancer le jeu\n\n---\n\n**Bon jeu! 🎮 Amusez-vous bien avec DreamWorlds!**\n"
